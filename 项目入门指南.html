HorizonArm 项目入门指南

给零机械臂基础的人：这个项目是什么、由什么组成、要补哪些知识、按什么顺序上手。

基于 G:\WL\Embodied_Arm\Project\Embodied_Arm-main 源码整理 · 2026-10-26

01一句话认识它

这是一台 6 自由度机械臂的"遥控器 + 大脑"：用 Python 写的桌面软件，既能手动拧每个关节，也能让它自己看着桌上的东西去抓，甚至听懂"把杯子拿过来"这种话。

手动控制6 个关节逐度微调、多关节同步、一键回零
夹爪串口控制开合角度，闭合力度可调
视觉抓取摄像头 + YOLOv8 识物，算出该去的位置
语音 / 手柄说话下指令，或用 Joy-Con 遥操

02硬件是谁在动

部件通信方式说明
6 个 ZDT 闭环电机CAN 总线（USB-CAN 转接，500k）每个关节一个电机，各有唯一 ID（1–6）。这是机械臂能动的唯一动力源
ESP32 夹爪串口 9600夹爪末端是一个舵机，用普通串口协议控制开合
USB 摄像头OpenCV 直连用于看画面、识别目标、做手眼标定
Joy-Con（可选）蓝牙 HID手持遥操作，替代鼠标点按钮

没有硬件也能玩：项目自带 MuJoCo 仿真（数字孪生），屏幕上会出现一个 3D 机械臂，拖滑块就能让它动。

03软件长什么样：三层结构

理解这三层，整个项目就通了。上层能用、中层能改、下层是个黑盒。

箭头方向 = 调用方向。参数从右侧配置层流入所有层。

记住这一条，能省你很多时间：凡是 Horizon_Core/ 里的东西都是编译好的二进制黑盒，不要试图改它；你的所有改动都应该写在 Embodied_SDK/（封装层）或者自己的新脚本里。

目录 / 文件规模作用与建议

05要补哪些知识（按优先级分三档）

必学 · 第一周
  • Python 面向对象：类与实例、继承、模块导入
  • 异常处理 / 线程：界面不卡靠子线程（QThread + 信号槽）
  • 关节 vs 末端：6 个关节角决定手在哪，这就是"自由度"
  • 角度单位：界面用"度"，底层算"弧度"
  • 电机三件套：使能 / 失能 / 位置模式，闭环控制是什么
  • CAN 总线 + 串口：什么叫 COM5、波特率 500k、设备 ID
用到再学 · 第二三周
  • DH 参数：用 4 个数字描述一节机械臂的几何关系
  • 正/逆运动学：关节角 → 手的位置（正）；想去某处 → 各关节该多少（逆）
  • 位姿与坐标系：xyz + 姿态角，变换矩阵怎么串起来
  • 相机内参与手眼标定：像素坐标怎么换算成机械臂能走的三维坐标
  • YOLO 目标检测：框出物体 + 置信度
  • MuJoCo / URDF：仿真模型怎么描述
  • PyQt5：信号槽、QTimer 刷新
可以先跳过
  • RRT 路径规划（避障用，内核已实现）
  • 深度估计（DepthEstimationSDK）
  • 层级决策系统内部逻辑
  • STM32 / 电机固件层协议
  • PID 参数整定（除非要自己调电机手感）

这些都在 .pyd 里跑，你调用即可，读不到也改不了。

06五步上手路线

1
先玩界面（30 分钟 · 无需硬件）
跑起来，把每个按钮点一遍，建立"这东西能干什么"的直觉。
conda activate embodied_arm
cd /d G:\WL\Embodied_Arm\Project\Embodied_Arm-main
python horizon_gui.py
成功后你会看到两个页签：⚙ 机械臂控制、📷 视觉抓取 + 具身智能。日志区会报 COM5 连不上——正常，因为没插硬件。
2
让机械臂在屏幕里动起来（1 小时 · 无需硬件）
先建立"关节角 → 手臂姿态"的直觉，这是机械臂最核心的概念。
python example/mujoco_control.py
拖左侧滑块，观察每一节怎么联动。玩 10 分钟比读一小时书管用。
3
顺着调用链读源码（半天 · Ctrl+Click 就是干这个的）
只有一条主线，跟着跳六次就理解了整个项目：
horizon_gui.py
 └→ gui/main_window.py        主窗口怎么组装界面
     └→ gui/motor_panel.py    "连接"按钮点了发生什么
         └→ gui/core/motor_manager.py   怎么做单位换算、怎么调度 6 个电机
             └→ Embodied_SDK/motion.py  create_motor_controller 怎么创建
                 └→ Horizon_Core（黑盒，到此为止）
配套读 gui_report.md 的第二节和第五节，每个文件干什么、依赖关系都列好了。
4
接上硬件，控制单个关节（1 小时 · 需要真机）
先确认最基本的"能让电机转"，再谈复杂功能。
python example/quickstart_guide.py
它会交互式问串口号和电机 ID。成功后跑 example/test_interactive.py，那是 40+ 功能的完整工具，能试所有控制模式。
5
按兴趣挑一个方向深入（持续）
三条路，各自有对应的教学示例：
  • 视觉抓取：example/control_sdk_examples/visual_grasp_example.py → 读 Embodied_SDK/visual_grasp.py（854 行，最厚的 SDK 模块）
  • 手柄遥操：joycon_control_example.py → 读 joycon.py
  • AI / 语音：example/ai_sdk_examples/LLM_usage.py → 读 ai.py、embodied.py

07新手最容易踩的五个坑

1. 电机不使能就不动。连上之后必须"使能"（enable），电机才接受运动指令，否则你发什么都石沉大海。失能状态下手推才推得动。

2. 角度单位和你想的不一样。界面上是"度"，底层算的是"弧度"，中间还有减速比和方向换算：关节角 = 电机编码器角 × 方向 / 减速比。这些换算在 motor_manager.py 里做，改参数前先看懂它。

3. COM 口号不是固定的。代码里默认 COM5，那是下拉框第一项，不是你的实际口号。插上 USB-CAN 后去设备管理器看，实际可能是 COM3、COM7 任意值。

4. 千万别升级 numpy。内核是编译好的，只认 numpy<2.0。装任何新包时如果它把 numpy 拉到 2.x，整个项目立刻崩，且报错信息会非常诡异。装包后跑一次 python verify_sdk_integrity.py 确认。

5. 紧急停止记住是空格键。机械臂真动起来的时候，手忙脚乱找按钮会出事。桌面软件层面还有红色"紧急停止"按钮，两者等效。

08总结成一句话

这个项目的本质是：把"给 6 个电机下发角度指令"这件事，包装成一个能点、能看、能说话的上位机。

所以你学的时候记住两条主线就够了——一条是控制链（按钮 → 管理器 → SDK → CAN → 电机），一条是感知链（摄像头 → 识别 → 坐标换算 → 变成一条运动指令）。两条链在"运动指令"这一步汇合。剩下的所有模块，都是这两条链上的插件。
